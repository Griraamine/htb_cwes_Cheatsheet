


## Tools

#### Hydra

Syntax: 

```
$ hydra [login_options] [password_options] [attack_options] [service_options] (-h for help) 
```


#### Medusa

brute forcing tool 
Syntax: 

```
$ medusa [target_options] [credential_options] -M module [module_options] (nothing for help) 
```


#### username-anarchy

a tool that generates possible usernames using different maming patterns 
Syntax: 

```
$ ./username-anarchy vorname name > output.txt
```


#### CUPP

a tools thats designed to create highly personalized password wordlists that leverage the gathered intelligence about your target.
Syntax: 

```
$ python cupp.py -i
```
